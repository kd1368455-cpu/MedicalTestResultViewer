# MedicalTestResultViewer

MedicalTestResultViewer は、医療検査機器から連携される検査結果を  
閲覧する業務システムをイメージした **検査結果ビューア画面のUIモック** です。  

血液検査・心電図・画像検査などの結果表示を想定し、  
1枚の HTML ファイル内で画面レイアウトとスタイルを構成しています。

本プロジェクトは Visual Studio Code を使用して開発しました。

---

## 🎯 プロジェクトの目的

- 医療系業務システムにおける **検査結果画面のUI構成** を練習すること  
- 異常値の強調表示や検査履歴など、**医療現場で必要になりそうな情報配置** を考えること  
- 派手さよりも、**業務システムらしい「見やすさ」「情報整理」** を意識した画面を作ること  
- HTMLだけでどこまで業務UIの雰囲気を表現できるかを試すこと  

---

## 🖥️ 画面構成（UIモック）

### 患者情報エリア
- 患者ID（例：P-20240522）  
- 患者氏名（例：北都 太郎）  
- 検査種別（血液検査 / 心電図 / 画像検査 などの想定ラベル）  
- 検査日（入力欄のみ・動作はしない）

### 検査結果エリア
- 検査項目名  
- 結果値（ダミー値）  
- 基準値（ダミー範囲）  
- 判定（基準値内 / 要経過観察 / 異常値）  
- コメント（医療現場をイメージした説明文）

**異常値や要経過観察の項目は色を変えて強調表示**し、  
医療系システムで重要な「危険度の視覚的な区別」を意識しています。

### 検査履歴エリア
- 直近の検査日・検査種別・概要・判定をテーブル形式で表示  
- 判定ごとにラベル（ピル型のタグ）を使い、状態が一目で分かるように構成  

---

## 🧩 UI設計のポイント

- **ダークテーマ＋アクセントカラー** による業務システム風デザイン  
- テーブルレイアウトを中心とした、**情報密度の高い画面構成**  
- 異常値・要注意・基準値内などを色分けし、**視線誘導を意識した設計**  
- 実務で使われるような「検査結果ビューア」の雰囲気を意識  

---

## 🛠️ 使用技術

- **HTML5**  
  - 画面レイアウト  
  - テーブル構造  
  - 入力フォーム要素（見た目のみ）

- **CSS（`<style>` タグ内に記述）**  
  - ダークテーマデザイン  
  - テーブル・カードレイアウト  
  - 強調表示（色・余白・境界線など）

※JavaScript は使用しておらず、画面はあくまで **静的なUIモック** です。  
　検査結果や履歴は、サンプルデータとして HTML 内に直接記述しています。
